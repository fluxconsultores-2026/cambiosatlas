¿Por qué cambian tantos códigos?

Chile y Costa Rica van a usar un mismo sistema. Cuando los dos países usan el mismo código para cosas distintas, uno de ellos lo cambia. En cada cambio verás el código de antes y el de ahora.

¿Cómo buscar?

Escribe una transacción (MIGO), un código antiguo o nuevo (FERT, CR01), un tema (sociedad) o el número del cambio. También puedes elegir un módulo.
